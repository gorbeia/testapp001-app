# Optional seed images

Place `logo.png`, `map.png`, or other assets here if you want the seed script to use real files instead of generated placeholders.

- **`logo.png`** — demo society logo (otherwise a solid-color placeholder is generated)
- **`map.png`** — floor plan for reservations (optional placeholder otherwise)

The seed pipeline uses [../seed-images.ts](../seed-images.ts), which prefers these files when present.
